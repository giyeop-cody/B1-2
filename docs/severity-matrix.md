# 치명도 등급 매트릭스

> 사전평가 #17 suggestion 대응: 치명도 등급별 우선조치 기준표

## 등급 정의

| 등급 | 명칭 | 기준 | 예시 | 조치 시한 |
|------|------|------|------|-----------|
| **P0** | Critical | 서비스 완전 중단, 데이터 손실 | OOM으로 프로세스 종료, Deadlock으로 무응답 | 즉시 (≤5분) |
| **P1** | High | 서비스 심각 저하, 부분 중단 | CPU Spike로 응답 지연, 타임아웃 다발 | 30분 이내 |
| **P2** | Medium | 서비스 경미 저하, 경고 | 메모리 점진 증가 (아직 임계치 미도달) | 4시간 이내 |
| **P3** | Low | 잠재 위험, 모니터링 대상 | 로그 경고(WARNING), 리소스 사용량 추세 | 다음 영업일 |

## 조치 매트릭스

| 등급 | 1차 조치 | 2차 조치 | 에스컬레이션 |
|------|---------|---------|-------------|
| P0 | 환경변수 긴급 조정 + 재시작 | 근본 원인 분의 (로그/스택) | 즉시 팀 리드 보고 |
| P1 | 환경변수 조정 (재시작 optional) | 로그 분석 + 패턴 확인 | 1시간 내 팀 리드 보고 |
| P2 | 모니터링 강화 (측정 간격 단축) | 재현 조건 분석 | 일일 리포트 |
| P3 | 추세 기록 | 정기 점검 시 반영 | 주간 리뷰 |

## agent-leak-app 장애별 등급

| 장애 | 등급 | 근거 |
|------|------|------|
| OOM (MemoryGuard 종료) | P0 | 프로세스 즉시 종료 → 서비스 중단 |
| CPU Spike (Watchdog 종료) | P1 | 응답 지연 선행 → 부분 중단 |
| Deadlock (무응답) | P0 | 서비스 중단 (헬스체크 통과 가능 → 탐지 지연 위험) |
